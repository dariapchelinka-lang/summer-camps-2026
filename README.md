# Flask-форма → Google Sheets

Готовый Python-проект на Flask для двухэтапного опроса «Летние лагеря 2026». Пользователь заполняет основную информацию и достижения, после чего приложение добавляет одну строку со всеми ответами в Google Sheets.

## Возможности

- адаптивная форма на русском языке;
- два шага с памяткой о сменах, личными данными и достижениями;
- вопросы по научной, учебной, общественной, спортивной и культурно-массовой деятельности;
- серверная проверка обязательных полей;
- запись заголовков таблицы при первом обращении;
- подключение к Google Sheets через `gspread` и `oauth2client`;
- админский вход и просмотр ответов участников прямо в приложении;
- группировка результатов по ФИО с отдельными блоками данных и достижений;
- поддержка Replit Secrets без хранения JSON-ключа в репозитории;
- понятные сообщения об ошибках;
- `GET /health` для быстрой проверки доступности приложения.

## Настройка Google API

### 1. Создайте проект в Google Cloud

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект или выберите существующий.
3. Перейдите в **APIs & Services → Library**.
4. Найдите и включите:
   - **Google Sheets API**;
   - **Google Drive API**.

Drive API нужен, чтобы библиотека могла открыть таблицу по её ID.

### 2. Создайте сервисный аккаунт

1. Откройте **APIs & Services → Credentials**.
2. Нажмите **Create Credentials → Service account**.
3. Укажите любое имя, например `flask-sheets-writer`.
4. Роли проекта для этой задачи обычно не нужны — доступ к самой таблице будет выдан отдельно.
5. Откройте созданный сервисный аккаунт, вкладку **Keys**.
6. Нажмите **Add key → Create new key → JSON**.
7. Скачайте JSON-файл. Это секретный ключ: не публикуйте его и не коммитьте в Git.

### 3. Поделитесь таблицей с сервисным аккаунтом

1. Создайте Google Spreadsheet.
2. Скопируйте email сервисного аккаунта из JSON-файла. Он выглядит примерно так:
   `flask-sheets-writer@your-project.iam.gserviceaccount.com`
3. Нажмите **Поделиться** в Google Sheets.
4. Добавьте этот email с ролью **Редактор**.
5. Название нужной вкладки таблицы по умолчанию должно быть `Лист1`. Если вкладка называется иначе, укажите её название в `GOOGLE_WORKSHEET_NAME`.

### 4. Узнайте ID таблицы

Для URL:

```text
https://docs.google.com/spreadsheets/d/1AbC...XyZ/edit#gid=0
```

ID — это часть между `/d/` и `/edit`:

```text
1AbC...XyZ
```

## Запуск в Replit

Добавьте значения в **Secrets** проекта:

| Имя | Значение |
|---|---|
| `GOOGLE_SHEET_ID` | ID вашей таблицы |
| `GOOGLE_WORKSHEET_NAME` | Название вкладки, например `Лист1` |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | Полное содержимое скачанного JSON-файла одной строкой |
| `ADMIN_PASSWORD` | Пароль для входа в кабинет администратора |

JSON можно вставить в Secret как есть, включая переносы строк. Приложение прочитает его из переменной окружения и не записывает на диск.

### Вход администратора

После добавления `ADMIN_PASSWORD` в Secrets нажмите **Вход для администратора** в правом верхнем углу формы. Вход выполняется по паролю, а авторизация сохраняется в защищённой Flask-сессии.

В кабинете результаты загружаются из той же вкладки Google Sheets и отображаются карточками:

- одна карточка на каждого участника;
- заголовок карточки — ФИО;
- основная информация и контакты;
- пять разделов достижений;
- ссылки открываются в новой вкладке.

Для просмотра результатов сервисному аккаунту достаточно роли **Редактор** на нужную таблицу. Пароль администратора не передаётся в Google Sheets.

После этого запустите:

```bash
python app.py
```

Приложение слушает `0.0.0.0:5000`.

Для запуска через Gunicorn:

```bash
gunicorn --bind 0.0.0.0:5000 app:app
```

## Локальный запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Сохраните скачанный ключ как `service-account.json` в корне проекта и задайте переменные окружения:

```bash
export GOOGLE_SHEET_ID="ваш_id_таблицы"
export GOOGLE_WORKSHEET_NAME="Лист1"
export GOOGLE_SERVICE_ACCOUNT_FILE="$(pwd)/service-account.json"
export SESSION_SECRET="длинная-случайная-строка"
python app.py
```

На Windows PowerShell:

```powershell
$env:GOOGLE_SHEET_ID="ваш_id_таблицы"
$env:GOOGLE_WORKSHEET_NAME="Лист1"
$env:GOOGLE_SERVICE_ACCOUNT_FILE="$PWD\service-account.json"
$env:SESSION_SECRET="длинная-случайная-строка"
python app.py
```

## Проверка

Проверить, что сервер запущен:

```bash
curl http://127.0.0.1:5000/health
```

Ожидаемый ответ:

```json
{"service":"flask-google-sheets-form","status":"ok"}
```

Затем откройте главную страницу и отправьте тестовую заявку. Подключение к Google Sheets выполняется при первой отправке, поэтому главная страница будет открываться даже до настройки ключей.

## Важные замечания по безопасности

- Не размещайте JSON-ключ сервисного аккаунта в GitHub, Replit Files или публичном архиве.
- Для Replit используйте Secret `GOOGLE_SERVICE_ACCOUNT_JSON`.
- Никому не выдавайте сервисному аккаунту больше прав, чем нужно: достаточно доступа **Редактор** только к нужной таблице.
- Если ключ оказался опубликован, удалите его в Google Cloud и создайте новый.
- Для публичной формы в production дополнительно подключите CAPTCHA или rate limiting.
